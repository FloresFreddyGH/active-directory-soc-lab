# Portfolio summary

**Title:** Active Directory SOC Lab

**Status:** In progress — Windows Server foundation completed

I am building an Active Directory lab on Ubuntu with QEMU/KVM to practice Windows domain administration and eventually investigate authentication and account changes in Wazuh. So far, I have checked host capacity, configured a Windows Server 2025 VM with UEFI, installed Standard Evaluation with Desktop Experience, and completed the first login.

The next stage is configuring the server's identity, networking, and domain services. Domain creation, a joined client, and security detections are planned and should not yet be presented as completed work.

Evidence: screenshots 01–05 and the October 30 journal entry. This is a separate project from my completed Wazuh and Azure labs.
